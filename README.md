# The Devotional Study Bible (TDSB)

A comprehensive HTML-based Bible reading and study application providing organized access to the entire Bible, introductory courses, and curated passages for spiritual growth.

## Introduction

The Treasure Chest is a personal Bible study resource featuring three primary sections:

- **Introductory Bible Reading Courses**: 12 structured courses covering fundamental Biblical topics including an overview of the Bible, the life and teachings of Jesus, Paul's ministry, salvation, prayer, the Holy Spirit, Old Testament leaders, and social justice themes
- **Every Book Of The Bible**: Complete navigation to all 66 books of the Bible
- **Every Chapter Of The Bible**: Comprehensive chapter-by-chapter reference of the entire Bible
- **Gem Passages**: Curated collection of meaningful Bible verses for meditation and study

## Getting Started

### Running the Application

1. Open `index.html` in any modern web browser
2. The interface will load with three collapsible sections
3. Click on section headers to expand/collapse content
4. Navigate to individual Bible books or courses through the provided links

### Project Structure

```
TreasureChest/
├── index.html                          # Main application interface
├── tdsb.js                             # JavaScript for interactive features
├── ecotb.js                            # Every Chapter Of The Bible script
├── Every Book Of The Bible/            # All 66 Bible books (HTML files)
├── Every Chapter Of The Bible/         # Chapter-by-chapter reference
├── Introductory Bible Reading Courses/ # 12 structured study courses
├── Gems/                               # Curated passages for meditation
```

### Requirements

- Modern web browser (no server or build process required)
- All content is static HTML/JavaScript

## Features

- **Collapsible Navigation**: Click headers to expand/collapse sections
- **Complete Bible Reference**: Access every book and chapter
- **Structured Learning**: Introductory courses for systematic Bible study
- **Personal Reading Plans**: Support for custom reading schedules
- **Gem Collection**: Quick access to meaningful passages

## Usage

The application is purely client-side. Simply open `index.html` in your browser to begin exploring Bible content and study courses.
